# Want to Watch

One shelf for books, movies, and TV. Log a title, mark it want, in progress, or done, and see what's up next across all three in one queue.

- Quick add or full details (season for TV, year, where to find it, notes), plus an Other type for things like manga
- Up Next: what you're in the middle of, then your ranked queue
- Start / Done buttons, 1–5 star ratings, filters, search, undo
- Back up and restore with a copy-and-paste code

Everything is saved in your browser (localStorage). Nothing is sent anywhere.

Live: https://ivantools.github.io/media-watch-tracker/
